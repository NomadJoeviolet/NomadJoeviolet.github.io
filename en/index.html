09 FIELD RECORDS
01 Team project 2026.03—2026.08

Humanoid Dual 7R-Arm Engineering Robot

Embedded Lead · Architecture Design and Algorithm Development

Led development of the onboard control system for a humanoid dual seven-axis arm. Built input routing, task scheduling, and a highly portable layered arm-control framework, with independent 1 kHz control for the left and right arms plus analytical and iterative numerical solutions for 7-axis inverse kinematics. Identified and compensated gravity parameters from multi-pose samples, and adapted the system to the arms’ mirrored structures and joint-to-motor mapping.

  • STM32H723
  • C++17
  • FreeRTOS
  • FDCAN
  • MATLAB

02 Team project 2026.07—2026.08

Humanoid Dual-Arm Teleoperation Controller

Embedded Lead · Operator-Side Architecture and Control Pipeline Development

Structured the fourteen-joint mapping and state-acquisition pipeline for the dual-arm operator side, and implemented a command-delivery framework for MIT force-position control. Added gravity compensation to the control pipeline and used Python/MATLAB for gravity-compensation parameter identification and offline validation. The current scope covers only the enabled compensation and validation work.

  • STM32G474
  • C++17
  • FreeRTOS
  • FDCAN
  • Python
  • MATLAB

Embedded Lead · Code Architecture, Algorithm Development, and Performance Optimization

Built a layered control pipeline covering inverse kinematics, trajectories, gravity compensation, and coordinated safety handling. Used SystemView and Cache/ITCM observations to locate performance behavior, then continued improving the architecture and algorithms.
